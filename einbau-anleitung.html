Anleitung

Den Chat auf Ihrer Website einbauen

Es gibt zwei Wege: einen Link oder Button, der den Chat öffnet, oder ein Chat-Fenster, das direkt auf Ihrer Seite sitzt. Beides geht ohne Programmierkenntnisse.

Vorher: Ihr Chat-Link

  1. 1

    Chat-Link bereithalten

    Nach der Einrichtung erhalten Sie von uns Ihren persönlichen Chat-Link per E-Mail. Er enthält Ihre Betriebskennung und Ihren Tarif und sieht so aus:

    https://termivox.com/kunden-chat.html?kunde=IHRE-KENNUNG&tarif=IHR-TARIF

  2. 2

    Link zuerst selbst testen

    Öffnen Sie den Link im Browser am Handy und am Computer, und stellen Sie dem Assistenten eine Frage. Erst wenn das klappt, bauen Sie ihn ein.

Variante A

Als Link oder Button

Der einfachste Weg. Der Chat öffnet sich in einem eigenen Fenster oder Tab. Das passt für Website, Instagram-Profil, Google-Unternehmensprofil und E-Mail-Signatur.

  1. 1

    Text und Ziel festlegen

    Legen Sie fest, wo der Link stehen soll, zum Beispiel auf einem Button „Termin online buchen“.

  2. 2

    Link eintragen

    Tragen Sie Ihren Chat-Link als Ziel des Buttons ein. Wenn Ihr Website-Baukasten einen Baustein für eigenen HTML-Code hat, können Sie stattdessen diese Zeile einsetzen und die Platzhalter ersetzen:

    <a href="https://termivox.com/kunden-chat.html?kunde=IHRE-KENNUNG&amp;tarif=IHR-TARIF">Termin online buchen</a>
  3. 3

    Speichern und prüfen

    Veröffentlichen Sie die Seite, tippen Sie am Handy auf den Button und schicken Sie eine Testnachricht.

Variante B

Als Fenster auf Ihrer Seite

Der Chat erscheint direkt in Ihrer Seite, ohne dass Besucher sie verlassen. So ist auch unsere Live-Demo eingebaut. Dafür brauchen Sie einen Baustein für eigenen HTML-Code oder Zugriff auf den Quelltext Ihrer Seite.

  1. 1

    Platz auf der Seite wählen

    Wählen Sie die Stelle, an der das Chat-Fenster stehen soll, zum Beispiel auf einer Seite „Termin buchen“.

  2. 2

    Code einfügen

    Probieren Sie den Code vor dem Einbau einmal auf einer Testseite aus, nicht gleich auf Ihrer echten Website. Ersetzen Sie dazu die beiden Platzhalter durch Ihre Angaben aus dem Chat-Link:

    <iframe src="https://termivox.com/kunden-chat.html?kunde=IHRE-KENNUNG&amp;tarif=IHR-TARIF"
        title="Termin-Chat"
        width="100%" height="640"
        style="border:0; max-width:420px;"
        loading="lazy"></iframe>

    Die Höhe von 640 Pixeln ist ein Vorschlag. Passen Sie sie an Ihre Seite an.

  3. 3

    Am Handy prüfen

    Rufen Sie die Testseite am Handy auf. Prüfen Sie, ob das Eingabefeld und die Knöpfe sichtbar sind und ob eine Testnachricht ankommt. Erst danach bauen Sie den Code auf Ihrer echten Website ein.

Ob sich fremder Code einbetten lässt, hängt von Ihrem Website-Baukasten ab. Geht es nicht, nutzen Sie Variante A.
